# MiniMart Sales Analysis — Entry Level

A small portfolio/practice project for an entry-level Data Analyst.

## Objective
Use **Python + Pandas**, **SQL**, and **Matplotlib** to clean a messy retail dataset,
detect and handle outliers, answer business questions, and present findings.

## Business Questions
1. How much revenue and profit did the store generate?
2. Which cities and categories perform best?
3. Do higher discounts reduce profit?
4. Which products contribute the most revenue?
5. Are delivery time and customer rating related?
6. Which unusual values need investigation before analysis?

## Data
`data/minimart_sales.csv`

The synthetic dataset intentionally contains duplicates, missing values, inconsistent
city labels, invalid quantities, and outliers in quantity, unit price, and delivery time.

## Workflow
1. Inspect data
2. Clean duplicates, missing values and inconsistent text
3. Validate invalid values
4. Detect outliers using IQR
5. Create revenue, cost and profit
6. Analyze with Pandas
7. Practice selected questions in SQL
8. Present four findings with Matplotlib
9. Write an executive summary and recommendations
